# SWYNEX INTERACTIVE DASHBOARD
  Superstore Sales and Profit Analysis Dashboard

## Project Overview

 I created an interactive Superstore Sales and Profit Analysis Dashboard using Microsoft Power BI to analyze sales and profit performance from 2014 to 2017.

## Project Objectives

* Analyze total sales and profit.
* Compare sales and profit across different categories, segments and regions.
* Analyze sales by shipping mode.
* Understand yearly sales trend.
* Use interactive slicers to filter and explore data.

## Tools Used

* Microsoft Power BI
* Superstore Sales Dataset

## Dashboard Features

* KPI cards showing key business metrics.
* Sales and Profit by Category.
* Sales and Profit by Region.
* sales by segment.
* Sales Trend by Year.
* Top 10 Products by Sales 
*  Sales by Shipping Mode.
* Interactive slicers for data filtering.

## Key Learnings

* Creating interactive dashboards in Power BI.
* Data visualization and business data analysis.
* Analyzing sales and profit performance.
* Using slicers to explore data dynamically.

## Conclusion

This project helped me improve my Power BI skills and understand how data visualization can support business analysis and decision-making.
